Does it actually move the animal?

The scenario player shows the system deciding. It cannot show whether the decision works, because a scripted animal walks the same path either way. So the animal here is not scripted: when the emitter fires, the animal's response is drawn from the behavioural prior, it physically turns, stops, keeps coming or bolts, and the encounter runs to a real resolution.

One run would prove nothing. So every encounter is run times, against a control arm that is identical except the emitter never fires.
